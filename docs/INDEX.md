## 🔄 文档维护

### 更新规则
- **重大功能变更**: 更新 README.md 和 FORMATS.md
- **技术架构变更**: 更新 DEVELOPMENT.md
- **Bug 修复**: 更新 TROUBLESHOOTING.md 和 CHANGELOG.md
- **部署流程变更**: 更新 DEPLOYMENT.md
- **结构优化**: 更新 PROJECT_STRUCTURE_OPTIMIZED.md

### 添加新文档

1. **用户指南** → 放入 `guides/`
2. **技术文档** → 放入 `technical/`,添加日期后缀(如 `topic-2025-11-05.md`)
3. **历史文档** → 移至 `archive/`

### 文档命名规范

- **指南类**: `OPERATION.md` (如 DEVELOPMENT.md)
- **技术类**: `topic-YYYY-MM-DD.md` (如 callout-optimization-2025-11-05.md)
- **归档类**: 保持原名,移至 archive/
